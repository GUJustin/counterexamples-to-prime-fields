# Intrinsic first-order list search

The user prioritizes intrinsic tightness, not further method-optimality
refinements. Primes p comparable to code length n suffice to test the
first-order list-size bound directly, even though they cannot support
a superlinear number of scalar labels for the line-amplification route.

The finite search checks all273 odd-exponent binomial families at seven
primes17 through137. For each full candidate bank, coordinatewise modes
maximize the total number of agreements with any word. No tested modal
word has three candidates above the first-order sufficient curve. This
does not optimize subbanks or prove a family-wide asymptotic statement.
The saved data includes all words and candidate agreement counts.

DICKSON_FIRST_ORDER_LIMIT.md separately proves a restricted-family
constant-list bound for the standard quarter-rate Dickson bank, even
allowing arbitrary candidate subsets and arbitrary words on F_p^*.
It fills the r2,j1 case deliberately excluded from the prior
higher-binomial-section capacity argument. The constant is deliberately
loose; no practical decoding improvement is claimed.

An exact verifier checks its character-branch formulas and the two-orbit
decomposition at eight primes, plus the constant arithmetic. Fourier
estimates follow from the character-sum proof rather than finite tests.

No growing list in the first-order regime or superlinear fixed-gap
exception construction is established by this investigation.
