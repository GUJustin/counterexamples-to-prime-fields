# A moment ceiling for every whole-opposite-pair collision

September 18, 2026. Bounded negative result for one global
second-moment strategy. No search, rental, manuscript edit, or new
fiber-size guarantee.

The existing whole-mu4 obstruction extends substantially: even counting
**every** modular signature collision whose difference is constant on
opposite pairs cannot supply the needed global second moment. This
includes arbitrary compositions of every possible whole-mu2 exchange,
not just the exchanges already found. Adding signature-preserving
rotations still leaves the certificate below 5.2% of the required
collision count.

## Four remaining tags are determined

Partition mu256 into opposite pairs `{x,-x}`, tagged by `a=x^2` in
mu128. If two 136-subsets have identical partial patterns on these
pairs, their difference consists of `h` full pairs in the first subset
and `h` disjoint full pairs in the second. Write their tag sets `A,B`.
On the punctured domain neither set can use the pair tagged by 1.

The odd moments cancel automatically. Equality of all six moments and
the root product is precisely

```
sum(A^j) = sum(B^j), j=1,2,3,
product(A) = product(B).
```

Here each even root moment is twice the corresponding tag moment,
and a whole pair has product `-a`; the signs cancel between sets of
the same cardinality. These equivalences hold in the actual F_p.

For fixed `A`, and a fixed `(h-4)`-subset `C` of a potential `B`, the
three power sums and product of `B minus C` are determined. Newton
identities recover its first three elementary coefficients, and its
product is its fourth coefficient. Thus the four remaining roots are
unique. Counting the `(h-4)`-subsets of each `B` proves

```
# admissible B disjoint from A
 <= floor[ binom(P-h,h-4) / binom(h,4) ],       h>=5,
```

where `P` is the number of available pair tags. There are no disjoint
solutions for `1<=h<=4`, by the same Newton identities. The argument
uses only characteristic greater than three and nonzero tags; no
character-sum estimate or characteristic-zero lifting is involved.

## Exact aggregate ceiling

Put `N=binom(255,136)`. For given `A,B`, the common root subset has
`136-2h` elements among the `255-4h` unused roots. This decomposition
is unique. Therefore all same-partial-pattern ordered signature
collisions, including the diagonal, number at most

```
E_punctured = N + sum_{h=5}^{59}
  binom(127,h)
  floor[binom(127-h,h-4)/binom(h,4)]
  binom(255-4h,136-2h).

E_punctured/N < 553442478287737.
```

The sufficient collision target is
`Q=N*(274980728111395088-1)+1`. Exact integer arithmetic proves
`496 E_punctured < Q`; the ratio is approximately `0.00201265915`.
Discarding the moment/product constraints would instead allow about
`1.30825e21` partners per support. Thus the four-root reconstruction
is doing essential work, rather than merely recounting the old sector
sizes.

## Rotation and full-complement closure

To include arbitrary rotations, relax to all 136-subsets of the full
mu256. Define

```
E_full = binom(256,136) + sum_{h=5}^{60}
  binom(128,h)
  floor[binom(128-h,h-4)/binom(h,4)]
  binom(256-4h,136-2h).
```

For a fixed full signature, a rotation by `zeta^t` can preserve the
product only if `136t=0 mod 256`. There are exactly eight such
rotations; the moment conditions can only reduce this number.
Rotations act invertibly on the six moments and normalize the
opposite-pair partition. Consequently the equivalence relation
generated by arbitrary same-sector signature collisions and allowed
rotations is contained in the union of at most eight rotated sector
relations. Across every signature together, its number of ordered
pairs is at most `8 E_full`.

Restricting back to subsets omitting 1 cannot increase this count.
The exact certificate gives

```
(8 E_full)/N < 1.416e16
(8 E_full)/Q < 0.052.
```

Complement in the **full** mu256 sends weight 136 to weight 120,
negates the six moments, and maps product `u` to `-1/u`. It conjugates
the sector relation to the corresponding relation at weight 120 and
commutes with rotations. An even number of complements cancels after
conjugation; an odd number cannot return to weight 136. This operation
therefore adds no new pairs to this bound. Complements in changing
punctured domains are not included in that assertion.

## What remains open

This is an upper bound on a *class of collisions*, not on the actual
global second moment or largest signature fiber. The baseline already
requires many collisions between different opposite-pair partial
patterns. The bound cannot be added to Cauchy--Schwarz as a disjoint
bonus. It also does not exclude a large fiber proved directly inside
one sector, or a weighted argument that identifies such a fiber.

It does rule out certifying the requested global second moment by
exhausting all whole-opposite-pair modular trades and their allowed
rotations. A useful new global variance argument must quantify
collisions that change these partial patterns, beyond the eight
product-stabilizing rotations. The existing antisymmetric lattice
trades do change partial patterns, so this result does not close that
direction; their separately audited contribution remains small.
